# housebot

Plugins and tools for a household [Hermes Agent](https://github.com/NousResearch/hermes-agent) bot
that several family members share over Discord.

| Path | What it is |
|------|------------|
| [`hermes-gmail-guard/`](https://github.com/eisene/hermes-gmail-guard) | Hermes plugin that asks a human to approve every Gmail read, naming the inbox and who asked |

Related: [eisene/gmail-multi-mcp](https://github.com/eisene/gmail-multi-mcp), a read-only Gmail MCP
server with paginated listing, regex search and credential redaction.

Clone with submodules:

```bash
git clone --recurse-submodules https://github.com/eisene/housebot.git
```
